Let’s fix it cleanly.

Why this happened (quickly)

  • nvm installs separate global tools per Node version

  • You installed pnpm while on Node 18

  • After switching to Node 20, pnpm isn’t there

Fix option A (recommended): re-enable pnpm via Corepack

Node 20 ships with Corepack, you just need to re-activate it.

corepack enable
corepack prepare pnpm@latest --activate

Verify:

pnpm -v

Fix option B (fallback): install pnpm globally

If for any reason Corepack fails:

npm install -g pnpm

Then:

pnpm -v

Run the app

Once pnpm is back:

pnpm dev

You should finally get:

▲ Next.js 16.x
- Local: http://localhost:3000

Open http://localhost:3000 🎉

corepack enable
